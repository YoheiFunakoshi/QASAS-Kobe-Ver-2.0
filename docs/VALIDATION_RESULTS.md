この表は、記載したSHA-256のファイルに対する受入基準です。DBまたは検体が更新された場合は同じ値になる必要はありません。

表中の `LV0`、`LV1`、`LV2` は「個別距離のユニーククローン数 / Read数」です。`≤LV2` は距離0～2の累積値です。

## 5. 再検証コマンド

```powershell
python scripts\validate_three_modes.py `
  --sample "<上記SHA-256と一致する検体>" `
  --database "<上記SHA-256と一致するCoV-AbDab_080224.csv>" `
  --format RG `
  --output-dir "QASAS 結果\validation"
```

CPM検体では `--format CPM` を指定します。`validation_summary.json` の集計値をこの文書と比較してください。処理秒数は計算機性能や同時実行状況で変わるため、受入基準には含めません。
